# تحقق صفحات الخصوصية وشروط الاستخدام

| البند | النتيجة |
| --- | --- |
| سياسة الخصوصية | تتضمن بيانات الاستخدام والحساب والبريد والتواصل، وخدمات خارجية، وشرحاً مشروطاً للإعلانات والكوكيز عند تفعيلها. |
| متطلبات Google | تتضمن رابط إعدادات إعلانات Google، وإفصاح الموردين الخارجيين والكوكيز، وملاحظة الموافقة حيث تنطبق للمنطقة الاقتصادية الأوروبية والمملكة المتحدة وسويسرا. |
| شروط الاستخدام | تتضمن طبيعة المحتوى، مراجعة مخرجات الذكاء الاصطناعي، الأدوات الخارجية، الملكية الفكرية، السلوك المحظور، والإعلانات/الروابط التابعة. |
| التذييل | يظهر رابطا سياسة الخصوصية وشروط الاستخدام بجانب رابط الإفصاح وروابط التواصل. |
| الاختبارات | يمر `scripts/verify-legal-pages.mjs` على صفحة الخصوصية وشروط الاستخدام ورابط التذييل وعدم التمرير الأفقي على الهاتف. |
| العرض | روجعت الصفحتان على سطح المكتب والهاتف؛ النص مقروء والهيكل متسق مع RTL والهوية الداكنة. |
