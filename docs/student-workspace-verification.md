# تحقق مساحة الطالب

تمت مراجعة صفحة `/student` بعد تنفيذها. تعرض الصفحة واجهة RTL داكنة متسقة مع AIToolBox، وتبدأ ببطاقة مسار مبسطة ثم أربع أدوات واضحة: خطة مذاكرة، أسئلة مراجعة، تبسيط مفهوم، وبطاقات حفظ.

| مجال التحقق | النتيجة | الدليل |
| --- | --- | --- |
| سطح المكتب | ناجح | تظهر بطاقة كل أداة ولوحة تفصيلية مباشرة أسفلها؛ تضم خطة المذاكرة مؤقتاً ومراحل قابلة للتأشير. |
| الهاتف | ناجح | تتكدس البطاقات ومدخلات الموضوع وخطة الجلسة عمودياً بترتيب واضح، ولا يظهر تمرير أفقي في اللقطة. |
| التفاعل | ناجح | يتحقق `scripts/verify-student-workspace.mjs` من تشغيل/إيقاف المؤقت، وإدخال إجابة مراجعة، وفتح خريطة المفهوم، وإضافة بطاقة حفظ، ورابط خطة الأيام السبعة، وفتح الأدوات الأربع تفاعلياً على هاتف بقياس 390×844. |
| منطق المساعدة | ناجح | اجتازت دوال الخطة والأسئلة وخريطة المفهوم والبطاقات اختبارات Vitest؛ تحافظ النصوص على التعلم الذاتي والمراجعة بدل تسليم إجابات جاهزة. |
