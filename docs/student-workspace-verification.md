# تحقق مساحة الطالب

تمت مراجعة صفحة `/student` بعد تنفيذها. تعرض الصفحة واجهة RTL داكنة متسقة مع AIToolBox، وتبدأ ببطاقة مسار مبسطة ثم أربع أدوات واضحة: خطة مذاكرة، أسئلة مراجعة، تبسيط مفهوم، وبطاقات حفظ.

| مجال التحقق | النتيجة | الدليل |
| --- | --- | --- |
| سطح المكتب | ناجح | يظهر العنوان، بطاقات الأدوات الأربع، ومدخل موضوع المذاكرة بجانب خطة الجلسة دون تداخل. |
| الهاتف | ناجح | تتكدس البطاقات والمدخل والخطة عمودياً بترتيب واضح ولا يظهر تمرير أفقي في اللقطة. |
| التفاعل | ناجح | يتحقق `scripts/verify-student-workspace.mjs` من إدخال موضوع، والتنقل بين الأدوات الأربع، ورابط خطة الأيام السبعة. |
| منطق المساعدة | ناجح | اجتازت دوال الخطة والـPrompts والبطاقات اختبارات Vitest؛ تحافظ النصوص على التعلم الذاتي والمراجعة بدل تسليم إجابات جاهزة. |
