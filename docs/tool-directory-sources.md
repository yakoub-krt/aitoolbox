## Editorial approach

The directory will use provider-owned website links and short factual summaries of a tool's stated use. It will not display customer reviews, user ratings, testimonials, or synthetic scores. The comparison UI will show declared criteria such as category, pricing model, Arabic support indicator, web availability, and short editorial notes that readers should verify on the provider page before subscribing.
