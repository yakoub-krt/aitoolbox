# تقييم نشر AIToolBox على Vercel

## الخلاصة

يمكن لـ Vercel تشغيل تطبيق Express، لكن **AIToolBox لا ينتقل إليه مباشرةً بمجرد ربط GitHub**. المشروع الحالي تطبيق كامل مبني على Express وtRPC وMySQL ومصادقة Manus وتخزين وخدمات مدمجة في Manus. لذلك يتطلب النشر الخارجي عملية نقل مضبوطة، لا مجرد ملف إعداد واحد.

توضح وثائق Vercel أن تطبيق Express يعمل كدالة Vercel واحدة، وأن نقطة الدخول يجب أن تصدّر التطبيق أو تبدأ خادماً بالطريقة التي تكتشفها Vercel.[1] كما أن إعدادات البيئة تدار لكل بيئة نشر ولا تنطبق على الإصدارات القديمة تلقائياً.[2]

| جزء المشروع الحالي | وضعه على Vercel | ما يلزم قبل النشر الخارجي |
| --- | --- | --- |
| واجهة React/Vite | قابل للنقل | تكوين بناء ومسار إخراج ثابت متوافق مع Vercel. |
| Express وtRPC | قابل للنقل بعد تهيئة نقطة الدخول | تحويل نقطة الخادم الحالية لتكون نقطة دخول Vercel مع اختبار `/api/trpc`. |
| MySQL وDrizzle | غير منقول تلقائياً | توفير قاعدة MySQL خارجية آمنة ونقل `DATABASE_URL` وترحيلات القاعدة. |
| تسجيل الدخول عبر Manus OAuth | غير جاهز للنقل كما هو | استبدال المصادقة بمزوّد OAuth مستقل أو تأكيد استمرار صلاحية تكامل Manus خارج استضافته قبل النقل. |
| التخزين وخدمات Manus المدمجة | غير منقولة تلقائياً | استبدالها أو توفير بدائل ذات مفاتيح وخدمات مستقلة. |
| Resend وAdSense | قابلان للنقل بعد التفعيل | نقل قيم البيئة فقط بعد توثيق النطاق وتوفير القيم من المالك. |

> نشر نسخة الواجهة فقط على Vercel لن يوفّر وظائف الدخول والإدارة والبيانات والنشرة كما تعمل الآن. يجب أن ينتقل الخادم والقاعدة والمصادقة معاً أو أن تبقى هذه الأجزاء على استضافة Manus.

## المسار المقترح

يبقى المسار الأقل مخاطرة هو نشر النسخة الحالية من لوحة Manus بعد إنشاء نقطة تحقق؛ إذ تتضمن استضافة Manus الخادم وقاعدة البيانات والمصادقة والتخزين المرتبطة بالمشروع. أما إذا كان Vercel شرطاً لديك، فالخطوة التالية هي **مهمة نقل مستقلة** تتضمن إنشاء قاعدة بيانات خارجية، اختيار مصادقة بديلة، نقل الأسرار، ثم اختبار بيئة معاينة قبل الإنتاج. لا ينبغي إلغاء أو تعديل تكاملات Manus الحالية قبل أن تنجح بيئة المعاينة.

## ما يلزم من المالك عند اختيار Vercel

| المطلوب | الغرض |
| --- | --- |
| تأكيد صريح بأن Vercel هو هدف النشر النهائي | لتفادي تحويل البنية الحالية بلا حاجة. |
| حساب Vercel متصل أو صلاحية ربط المستودع | لإنشاء مشروع Vercel من مستودع GitHub. |
| مزود MySQL خارجي و`DATABASE_URL` | للإبقاء على المقالات والمستخدمين والمفضلات والاشتراكات. |
| قرار لمزوّد المصادقة البديل | لأن تدفق Manus OAuth جزء من البنية الحالية. |
| أسرار الإنتاج الضرورية | مفاتيح التوقيع والتخزين والبريد، وتُدخل في إعدادات البيئة لا في Git. |
