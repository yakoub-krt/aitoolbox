# مصادر المقالات الموسعة

- [OpenAI Help: Prompt engineering best practices](https://help.openai.com/en/articles/10032626-prompt-engineering-best-practices-for-chatgpt): يشدد على وضوح التعليمات، توفير السياق، ومراجعة النتيجة ثم تحسين الطلب تدريجياً.
- [Google Workspace: Prompting Guide](https://workspace.google.com/learning/content/gemini-prompt-guide): يقدم دليلاً عملياً لمهارات كتابة الأوامر الفعالة حسب حالات الاستخدام.
- [OpenAI Privacy Policy](https://openai.com/policies/row-privacy-policy/): يوضح وجود إعدادات وضوابط للبيانات؛ يجب على المستخدم مراجعة سياسة كل خدمة وإعداداتها قبل إدخال بيانات حساسة.

تُستخدم المصادر مرجعاً للمبادئ العامة، ولا تُستعمل لإسناد ادعاءات مقارنة غير موثقة بين منتجات مختلفة.
