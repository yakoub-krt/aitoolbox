# مصادر خطة التعلم للمبتدئين

- [OpenAI Help: Prompt engineering best practices for ChatGPT](https://help.openai.com/en/articles/10032626-prompt-engineering-best-practices-for-chatgpt): يوصي بالوضوح والتحديد وإضافة السياق، ثم تحسين الأمر تدريجياً بعد مراجعة النتيجة.
- [Microsoft Learn: Embrace responsible AI principles and practices](https://learn.microsoft.com/en-us/training/modules/embrace-responsible-ai-principles-practices/): يقدم أساسيات الاستخدام المسؤول للذكاء الاصطناعي والحواجز العملية والسياسات والتدابير الوقائية.

تستعمل صفحة الخطة هذه المصادر كمراجع تدريبية عامة؛ ولا تقدم الخطة وعوداً بأن أي أداة ستنتج مخرجات صحيحة دائماً. تتضمن الخطة خطوة مخصصة للتحقق البشري وعدم إدخال البيانات الحساسة.
