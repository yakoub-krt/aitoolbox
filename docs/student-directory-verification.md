# تحقق دليل الطلاب

تمت مراجعة صفحة `/student-directory` بعد بنائها. تقدم الصفحة أربع تخصصات: العلوم والهندسة، اللغات والإنسانيات، البرمجة والحوسبة، والأعمال والتصميم. يعرض كل مسار ثلاث أدوات مع رابط رسمي مباشر وحالة استخدام ومسؤولية مختصرة.

| مجال التحقق | النتيجة | الدليل |
| --- | --- | --- |
| سطح المكتب | ناجح | يظهر العنوان، التخصصات الأربع، ولوحة تخصص مفتوحة بثلاث بطاقات أدوات وروابط واضحة. |
| الهاتف | ناجح | تظهر التخصصات وبطاقات الأدوات والروابط بعمود واحد مقروء من دون تمرير أفقي ظاهر. |
| تبديل التخصصات | ناجح | يتحقق `scripts/verify-student-directory.mjs` من فتح التخصصات الأربعة وعرض عنوان كل مسار. |
| الروابط المباشرة | ناجح | يتحقق السكربت من وجود ثلاث روابط HTTPS خارجية على الأقل لكل تخصص، إضافة إلى رابط مساحة الطالب الداخلي. |
| منطق البيانات | ناجح | يغطي اختبار Vitest التخصصات الأربعة، وعدد الأدوات (12)، وصحة روابط HTTPS. |
