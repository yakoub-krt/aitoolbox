# مصادر المواقع والبدائل المجانية

| الموقع | الرابط الرسمي | نتيجة التحقق |
| --- | --- | --- |
| Photopea | https://www.photopea.com/ | يعرّف نفسه كمحرر صور مجاني يعمل في المتصفح ويذكر أن الملفات لا تُرفع إلى خوادمه. |
| GIMP | https://www.gimp.org/ | الموقع الرسمي يعرّفه كمحرر صور مجاني ومفتوح المصدر متعدد المنصات. |
| LibreOffice | https://www.libreoffice.org/ | الموقع الرسمي يصفه بحزمة مكتبية مفتوحة المصدر بلا تكلفة. |
| Zotero | https://www.zotero.org/ | الموقع الرسمي يصفه بأداة مجانية لتنظيم المراجع والاقتباسات والبحث. |
| Inkscape | https://inkscape.org/ | الموقع الرسمي يصفه بأداة تصميم مجانية ومفتوحة المصدر للرسم المتجهي. |
| Excalidraw | https://excalidraw.com/ | يتيح الرسم داخل المتصفح ويذكر حفظ الرسوم في تخزين المتصفح، مع تنبيه للزائر بحفظ الملف بانتظام. |
| Audacity | https://www.audacityteam.org/ | الموقع الرسمي يصفه ببرنامج مجاني ومفتوح المصدر لتسجيل وتحرير الصوت. |
| Kdenlive | https://kdenlive.org/ | الموقع الرسمي يصفه بمحرر فيديو مجاني ومفتوح المصدر متعدد المنصات. |

لا تتعامل الصفحة مع كون الخدمة «مجانية» كضمان دائم لأي خطة أو ميزة؛ تُعرض حالة الاستخدام بصياغة حذرة ويُطلب من الزائر مراجعة شروط الموقع قبل البدء.
